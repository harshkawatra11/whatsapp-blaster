01C / Poster & Brochure (optional)

Paste Google Drive links here — must be shared as "Anyone with the link can view." The poster is sent as a real image attachment, with your message as its caption. The brochure is added as a plain link line under the message instead (WhatsApp has no way to hide a link behind text, so the link itself is what recipients see). Leave either blank to skip it. A CSV column (POSTER LINK / ATTACHMENT LINK) overrides these per-row if present.
